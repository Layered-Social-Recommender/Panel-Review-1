## Layered Social Recommendation Systems for Online Social Networks

This repository contains the work completed by the project team for
**[23CSE498 Project Phase 2] Panel Review 1**.

The repository includes the datasets, preprocessing pipelines, social
graph construction and analysis, behavioral feature extraction, MCDM
analysis, and other implementation work carried out during this phase.

---

## Project Overview

The project aims to develop a layered social recommendation framework
for Online Social Networks (OSNs), integrating social graph information,
user behavior, contextual signals, trust evaluation, recommendation
models, and explainability.

The proposed framework follows a modular six-layer architecture:

1. Data Layer
2. Social Graph Layer
3. Feature and Context Layer
4. Trust and Safety Layer
5. Recommendation Engine Layer
6. Explainability Layer

This repository documents the implementation and analysis carried out
towards these layers during the project phase.
